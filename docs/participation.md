# Participation and actor access

[Documentation index](README.md)

Explore → Event Home → Join as Actor → work/roles → availability → advisory/review → participation request.

Contracts: `GET /events/{id}/join-options`, `POST /events/{id}/participation-advisories`, `POST /events/{id}/participation-requests`. Advice does not approve a person. Organizers review selections; pending requests appear in My Events → Participating. Approved/partially approved actors reach `actor-dashboard.html?event={id}` for accepted responsibilities.

Organizers do not need Join as Actor for their own event. Identity comes from the session. Discovery is not city-gated; remote participation remains subject to event rules/access. Actor reports are scoped to accepted assignments. Knowing an ID is not authorization.
